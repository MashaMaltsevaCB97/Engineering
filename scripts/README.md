# HomeWork4

Код обращается к API сайта Shikimori, чтобы получить данные о доступных мангах.
ссылка на сайт [Shikimori](https://shikimori.io/mangas)

## Работа кода

Код `read_api.py`отправляет запрос на сайт с параметрами:

1. `limit=20` (получаем 20 записей)
2. `order=popularity` (сортируем по популярности)

Для запуска кода обязательна передача `User-Agent`, без него сайт блокирует доступ и выдает ошибку 403.

По итогу работы кода формируется таблица с названием столбцов: ID, название на английском и русском, оценку, тип (манга/манхва), статус.

Для работы с кодом необходимо установить все необходимые библиотеки. Ввести команду:

```bash
uv run scripts/read_api.py
```
