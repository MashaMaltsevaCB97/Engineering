# Engineering

Название: «Спектры флуоресценции растворов (катионы + гидразон L)»
Размер: 19 столбцов (1 столбец «Длина волны, нм» + 18 столбцов «Интенсивность излучения гидразона L при добавлении катионов») и 601 строк 
Ссылка: [Датасет в Google Drive](https://drive.google.com/drive/folders/1x0WZ3ai8SLnvWp-3WtmL7-3suHTT1pHO?usp=drive_link)
Описание:  Представленные данные получены с помощью спектрофлуориметра и отражают зависимость интенсивности излучения растворов комплексов «ион металла (Ме) — гидразон L». Измерения выполнены в рамках научно-исследовательской работы. Данные являются оригинальными и получены автором.

## Homework2


## HomeWork 5 и 6

Был создан файл `EDA.ipynb` для разведочного анализа данных и визуализации.
В ноутбуке содержится анализ данных со спектрами флуоресценции, а именно:

1. Проверка структуры данных (типы, пропуски, дубликаты);
2. Расчет базовых метрик (max, min, среднее значение);
3. Графики зависимости длины волны от интенсивонсти излучения некоторых элементов;
4. Матрица корреляции с оценкой связей между элементами;
5. Итоговые выводы об анализируемых даннных.

Визуализация данных проведена с помощью библиотеки «Plotly Express».

## HomeWork 7 и 8

Пакет `etl` находится в директории `src/etl` и реализует полный цикл подготовки данных.

### Структура пакета

- `extract.py` — загрузка сырых данных из CSV.
- `transform.py` — приведение типов и подготовка данных (ограничение до 100 строк).
- `load.py` — подключение к удаленной БД PostgreSQL и запись данных.
- `main.py` — CLI-интерфейс для запуска пайплайна.

Для работы требуется файл `.env` с кредами к БД (не хранится в репозитории).

Запуск пайплайна из командной строки:
```bash
uv run python -m etl.main --file-path "спектры.csv" --table-name "ваша_фамилия"
```
